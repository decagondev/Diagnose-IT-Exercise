**Named constraint (one sentence):** The constraint is conversion, not capacity: the company has no trusted path from a live business need to an owned, used workflow that doesn't run through a few specialists, so needs expire in the queue, shipped flows go unused, and demand leaks into ungoverned tools.

Any numbers in this pack are labelled **hypothetical** unless a source is linked.
